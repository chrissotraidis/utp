# UTP Issue #6 iOS 15 compatibility test 1

This is an isolated compatibility test for [Issue #6](https://github.com/chrissotraidis/utp/issues/6).
It does not replace UTP Preview 3 and is not a general stable release.

The candidate lowers the complete app, transformed engine, audio/media
dependencies, runtime shims, SDL layer, and FruCoRe Metal library to an iOS and
iPadOS 15.0 minimum. The normal UTP build remains at iOS/iPadOS 17.0 unless the
experimental minimum-version override is explicitly selected.

The iOS 15 build and package audits pass on the maintainer's current Xcode host,
but no physical iOS 15 or iPadOS 15 device is locally available. Support remains
experimental until the reporter or another tester completes the hardware checks.

## Requested test

Please report the exact iPhone or iPad model and OS version, then check:

1. The IPA installs and UTP reaches its first screen.
2. First-run game-data setup or import completes using data you are authorized
   to use. Do not upload game data, signing files, profiles, or credentials.
3. The original Unreal Tournament menu appears in landscape and a local match
   reaches gameplay with visible rendering and audible music/effects.
4. Touch movement, look, fire, menu selection, and the Menu/Gameplay mode switch
   work. If available, also test a controller and keyboard/pointer input.
5. Background UTP, reopen it, rotate between both landscape sides, and confirm
   that input and audio still work.
6. Open the server browser or join a known server if practical.

If something fails, attach screenshots and use UTP's **Export Logs** action.
Review the archive before sharing it. Never attach proprietary game data,
generated engine images, saves, Apple signing material, credentials, or device
identifiers.

## Installation

The IPA is unsigned and must be re-signed or installed through a compatible
sideloading workflow. Epic game data is not included. TrollStore compatibility
is a tester installation path, not a UTP entitlement or runtime dependency.

Known Preview 3 limitations still apply, including small original-menu text,
some incorrect shadow/alpha rendering, incomplete pointer-wheel coverage, and
limited device/performance breadth.

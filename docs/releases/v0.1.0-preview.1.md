# UTP v0.1.0 Preview 1

This is the first public developer-preview IPA for UTP, a native iOS and
iPadOS host for Unreal Tournament 99 using the OldUnreal v469e ARM64 runtime
and FruCoRe Metal renderer.

## What is included

- Native iPhone and iPad host with landscape Metal presentation.
- Offline Unreal Tournament matches with working physical-device audio.
- Editable touch gameplay and menu controls.
- Xbox controller gameplay when the controller is available at app launch.
- Original Unreal Tournament menu and community server browser.
- First-run game-data setup and manual folder or ZIP import.
- Transactional data installation, recovery, diagnostics, and save preservation.

## Installation

The release IPA is unsigned and must be re-signed with your own Apple account
before installation. AltStore Classic with AltServer, SideStore, Sideloadly,
or an Apple development-signing workflow can perform that step. It is not an
App Store or TestFlight installation.

UTP requires iOS or iPadOS 17 or later. Epic game data is not included. Follow
the first-run setup in UTP or import files from a copy you are authorized to
use. Epic, OldUnreal, and Apple terms still apply.

## Known Preview 1 issues

- Original text fields do not accept hardware-keyboard input, and **Type Text**
  does not currently provide working software-keyboard entry.
- Xbox controller hot-connect can require relaunching UTP.
- The controller-driven original-menu cursor remains skittish.
- **Press Escape to begin** can remain unresponsive or misleading while a
  server package download is still active.
- Original menu text is small, and some in-game shadows render incorrectly.

See [Known issues and technical debt](../KNOWN_ISSUES.md) for the complete
engineering ledger.

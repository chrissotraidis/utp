# UTP v0.1.0 Preview 2

Preview 2 is a focused input-stability update for UTP, the native iOS and
iPadOS host for Unreal Tournament 99 using the OldUnreal v469e ARM64 runtime
and FruCoRe Metal renderer.

## Fixed in Preview 2

- Hardware-keyboard text entry now works in original Unreal Tournament fields.
- UTP's virtual keyboard now enters printable characters in those fields.
- Xbox controllers can connect after UTP is already running without requiring
  an app restart.
- Hot-connected controllers are adopted as native extended gamepads, hide the
  touch overlay, navigate the original menu, and retain movement, look, and
  fire controls in gameplay.
- Menu/Gameplay switching and pause/resume remain usable after hot-connect.

These paths were accepted on a physical iPad with the controller initially
disconnected, connected through Bluetooth Settings after launch, then used in
the original menu and an Oblivion match. The same session reconfirmed hardware
and virtual-keyboard entry.

## Installation

The release IPA is unsigned and must be re-signed with your own Apple account
before installation. AltStore Classic with AltServer, SideStore, Sideloadly,
or an Apple development-signing workflow can perform that step. It is not an
App Store or TestFlight installation.

UTP requires iOS or iPadOS 17 or later. Epic game data is not included. Follow
the first-run setup in UTP or import files from a copy you are authorized to
use. Epic, OldUnreal, and Apple terms still apply.

## Known Preview 2 issues

- Physical mouse/trackpad movement and primary click are present, but pointer
  precision, secondary click, and wheel behavior remain incomplete.
- **Press Escape to begin** can remain unresponsive or misleading while a
  server package download is still active.
- Original menu text remains small.
- Some projectile/shadow rendering produces large black polygons.
- Broader lifecycle, multiplayer compatibility, performance, thermal, and
  device coverage remain developer-preview work.

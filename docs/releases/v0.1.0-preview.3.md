# UTP v0.1.0 Preview 3

Preview 3 completes UTP's first gameplay-grade keyboard and pointer path on
iPad and simplifies the in-game host menu around the controls that are actually
available in the current state.

## Fixed and improved in Preview 3

- Hardware WASD movement works in explicit **Gameplay Controls** mode while
  normal hardware-keyboard text entry remains available in **Menu Controls**.
- **Capture Mouse / Trackpad** requests native iPadOS pointer lock and provides
  relative gameplay look without a second competing cursor.
- Persistent 20%, 35%, 50%, 75%, and 100% mouse/trackpad speed presets are
  available directly in the three-dot panel.
- Pointer buttons, WASD, and an already-connected Xbox controller can be used
  together in the same match.
- The host menu now reports actual touch visibility when a controller auto-hides
  the overlay, hides irrelevant Arrange/Speed actions, and uses contextual
  **Open UT Menu**, **Escape / Back**, and **Open Server Browser** labels.
- The stock server-browser shortcut uses a slower, phase-logged path through
  Unreal's original Multiplayer → Find Internet Games menu.
- Held keyboard and pointer inputs are released on menu, mode, foreground, and
  device-lifecycle transitions to prevent stuck movement or buttons.

These paths were accepted on a physical iPad in an Oblivion deathmatch using an
attached keyboard and trackpad plus an Xbox controller. A higher pointer-speed
preset was comfortable, all tested buttons worked, and the conditional menu was
accepted in the final device build.

## Installation

The release IPA is unsigned and must be re-signed with your own Apple account
before installation. AltStore Classic with AltServer, SideStore, Sideloadly,
or an Apple development-signing workflow can perform that step. It is not an
App Store or TestFlight installation.

UTP requires iOS or iPadOS 17 or later. Epic game data is not included. Follow
the first-run setup in UTP or import files from a copy you are authorized to
use. Epic, OldUnreal, and Apple terms still apply.

## Known Preview 3 limitations

- Gyro aiming is not included.
- Pointer wheel/scroll behavior and controller models beyond the accepted Xbox
  path have not been separately validated on hardware.
- Original UWindow menu text remains small.
- Some projectile, shadow, or alpha effects can render as large black polygons.
- Physical-device server-browser compatibility is less broadly exercised than
  the proven Simulator and direct-connect paths.
- Audio-route interruptions, long lifecycle/soak behavior, performance,
  thermals, memory pressure, battery use, and broader device coverage remain
  developer-preview work.

# UTP 0.1.1

This update fixes recovery after an interrupted game-data import. If rollback was itself interrupted or hit an I/O error, retrying it could delete a content folder that had already been restored. Recovery now keeps the complete backup until restoration finishes, writes a completion checkpoint, and only then cleans up.

Rebuild UTP with PadMint and install it over the existing app using the same signing identity to retain its container. This release prevents the demonstrated retry failure; it cannot reconstruct files already lost by an earlier interrupted rollback.

## Validation

- A focused regression reproduced lost `Maps/old.unr` with the previous recovery implementation.
- The transaction suite passes interrupted commit, interrupted rollback and retry, interrupted rollback cleanup, successful replacement, cancellation, runtime support import, and existing settings preservation. Fixtures contain synthetic text, not game assets.
- App metadata is 0.1.1, build 4.
- This is not a claim of an exact physical-device or Files-provider selection reproduction. The picker policy is unchanged.

The release publishes only `UTP-v0.1.1-padmint.json` and `SHA256SUMS`. PadMint builds each app locally; no app or game data is included.

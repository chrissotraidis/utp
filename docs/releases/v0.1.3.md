# UTP 0.1.3

UTP now starts the engine at the size of the window that hosts the game. Earlier builds sized Unreal's startup viewport from the iPhone or iPad's main screen, so a game shown in a smaller or resized window, or on an external display such as a TV, could start at the wrong size. Later rotation, resizing and display moves already followed the window and are unchanged.

Touch controls now follow the **Auto-hide Touch Controls with Controller** setting while a controller is connected. Earlier builds hid touch when a controller connected and ignored later changes to that setting until the controller disconnected. Turning the setting off now shows touch immediately, and turning it on hides touch immediately. **Show Touch Controls** in the ••• menu keeps the controls visible with a controller connected by turning auto-hide off; turn it back on to hide them again. The settings panel's touch switch shows whether the controls are actually visible, and its row is now named **Auto-hide with controller**.

Rebuild with PadMint and install over the existing app using the same signing identity. Do not uninstall first.

## Validation

- `make test` passes, including new display-geometry checks (landscape, portrait-measured, 1x external-display-sized, unmeasured windows and invalid scale) and touch-configuration checks (default on, controller connected and disconnected, Show overriding a connected controller, persistence across reload).
- App metadata is 0.1.3/build 6.
- Physical TV and controller acceptance is pending: these changes have not yet been exercised on an external display or with a physical controller.

Only `UTP-v0.1.3-padmint.json` and `SHA256SUMS` are published. PadMint builds the app locally; no app or game data is included.
